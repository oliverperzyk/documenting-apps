# Demo_PR01 — wzorzec zestawu do zaliczenia

W katalogu znajduje się jeden kompletny model dokumentacji Projektu 01 „Bąbelkowy pojedynek”. Obejmuje wszystkie kategorie oddawanych materiałów, także plan E01/H1, dane, wyniki, logi, audyt, retesty, dziennik pracy i przygotowanie obrony.

**Konwencja dydaktyczna:** dokumenty i pomiary są demonstracyjne. Zgodnie z ustaleniem pliki źródłowe są pustymi placeholderami z komentarzem. We własnej pracy uczniowskiej wymagany jest działający kod i rzeczywiste dowody. Ten wyjątek dotyczy wyłącznie niniejszego wzorca.

## Co stanowi paczkę do oddania?

Folder `TiDPI_PR01_demo_sortowanie_babelkowe` przedstawia katalog oddawanego projektu. Obok znajduje się odpowiadający mu ZIP z dokładnie jednym katalogiem głównym. Niniejsza instrukcja i mapa kompletności są dodatkami objaśniającymi zestaw, poza paczką uczniowską.

Nie należy przepisywać wyników ani wpisów tego zespołu do własnego raportu. Wzorzec pokazuje sposób opisu i układ dowodów. Szczególnie ważne jest zachowanie hipotezy, która nie uzyskała pełnego wsparcia: próg spełnia 9 z 12 przypadków.
