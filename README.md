# `@oliverperzyk/documenting-apps`

Repozytorium zawiera indywidualne jak i grupowe rozwiązania zadań oraz materiałów na przedmiot **Testowanie i Dokumentowanie Projektów Informatycznych**. Zawiera również prostą nakładkę do ułatwienia sobie pracy z plikami (automatyczne formatowanie plików z Prettierem i clang-format) oraz linterem dla plików Markdown.

## 🏅 Rozwiązania indywidualne

Rozwiązania zadań z materiałów indywidualnych (od TiDPI_03 do TiDPI_12) znajduje się w folderze `tasks/individual`, z kolei, ten folder dzieli się na dwa katalogi:

- [`📦 tasks/individual/bundles`](./tasks/individual/bundles/) - Zawiera pliki `.zip` gotowe do pobrania przez prowadzącego przedmiot, które zawierają tylko i wyłącznie pliki wymagane do dołączenia do raportu. Dzięki temu, nie trzeba pobierać wszystkich (w tym zbędnych) plików.
- [`📚 tasks/individual/solutions`](./tasks/individual/solutions/) - Zawiera wszystkie pliki, które były wykorzystywane podczas rozwiązywania zadań.
